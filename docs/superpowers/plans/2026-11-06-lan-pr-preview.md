# PR 局域网验收预览实施计划

目标：usmapgames.com 每个通过 CI 的 PR 提供绑定最新 SHA 的独立局域网预览，并发送到飞书。仅静态构建，不发布公网，不修改生产域名。

约束：原项目存在用户未提交改动，必须保留；构建使用独立 detached worktree，Node 26，DEPLOY_ENV=preview；服务仅绑定指定 RFC1918 LAN 地址，端口从 8800 起分配，不使用测试端口 8787；预览页面及资源 no-store/noindex，不暴露源码、隐藏文件、目录列表或符号链接外部目标。

- [x] 静态 HTTP 预览：安全路径解析、MIME/HEAD、404、生成版本元数据、禁用索引；HTTP 与路径穿越测试 RED→GREEN。
- [x] 预览管理器：SQLite 保存每个任务/PR 的端口、SHA、构建路径、URL、错误与通知记录；幂等启动/更新、端口冲突、构建失败、关闭回收、服务重启恢复，测试 RED→GREEN。
- [x] 真实构建适配：仅在独立 worktree 构建明确 SHA；校验 clean HEAD、预览 noindex、无生产 analytics；回收时只删除管理器自己创建的 worktree。
- [x] 接入 CI 审核提醒：CI 通过→构建/启动/健康检查→复核 CI/SHA→飞书附测试 URL；预览失败告警、不发送旧链接；已存在待审 PR 补发，关闭停止预览。
- [x] 配置/文档：默认关闭、显式 LAN 地址与端口段、最多同时 5 个预览、Mac/网络可用性和 HTTP 内置浏览器限制。
- [x] 全量测试与构建，核对没有活跃的本地开发/验证后安全重启；用真实待审核 PR 验证 LAN URL、SHA/页面和飞书送达，不自动合并。

复核重点：不允许构建任意传入路径；URL 与 PR SHA 严格匹配；任何错误不复用旧版本链接；静态服务器不运行 Worker/API；所有监听服务器均由当前进程持有，无任意 PID 终止；PR 关闭后保留/删除规则仅限自己创建的临时 worktree。无需 Grok。
